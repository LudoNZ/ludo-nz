# Ludo.co.nz

A personal portfolio website to showcase front-end development skills — built with **Next.js 14**, **React**, **SCSS Modules**, and hosted on **Firebase Hosting**.

![Ludo Logo](/public/logo.svg)

---

## 🚀 Tech Stack

- [Next.js 14](https://nextjs.org/)
- [React 18](https://react.dev/)
- [SCSS Modules](https://sass-lang.com/)
- [Firebase Hosting](https://firebase.google.com/)

---

## 📦 Local Development

Install dependencies:

```bash
npm install
```
